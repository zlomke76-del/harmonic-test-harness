# Public Claim Boundaries

This harness separates four questions that must not be collapsed:

1. **Was relevant domain state constituted for the examination?**
2. **What governance disposition did Harmonic return for the exact submitted consequence?**
3. **Did the examined execution boundary enforce the required authorization?**
4. **Did a real production consequence occur or remain unreachable?**

A finding at one layer does not automatically establish the next.

## Raw vs Governed

The `raw-vs-governed` example uses a frozen synthetic proposal and frozen synthetic authority-state fixture.

It demonstrates a terminal-visible contrast between:

- an intentionally ungoverned local synthetic path; and
- a path that obtains a current Harmonic determination before the same local synthetic consequence is allowed to proceed.

It does **not** claim that:

- a live LLM generated the fixture;
- the raw lane performed an external HTTP disclosure;
- Harmonic independently discovered the domain transition from raw facts;
- every production executor is non-bypassable.

## Execution authority

Descriptive or evidentiary labels such as `PASS`, `APPROVED`, or `ADMISSIBLE` are not execution permits.

A consequence-bearing public demo must require explicit executable permission under the current contract and otherwise fail closed.
