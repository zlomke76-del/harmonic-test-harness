## Property at risk

**A Specialty Pack must distinguish source freshness and continuity from current source standing.**

A source may remain authentic, attributable, current, available, high-confidence, unchanged in content, and historically primary while no longer being the source currently governing a proposition.

The exact distinction frozen for V117 is:

**historically authoritative ≠ currently governing for this proposition**

## Frozen source-responsibility map

- content
- provenance

## Pair

### Case A

Source A and Source B are both present and current. Source A's governing interval contains the observation time. Source A is therefore the current governing source for the frozen proposition.

### Case B

The two source records themselves are unchanged. Their content, provenance, freshness, availability, confidence and static hierarchy positions are unchanged. Source A's governing interval has ended and Source B's governing interval now contains the observation time.

The only substantive input change is the independently attributable source-authority state.

## Primary dispositions

- **PASS** — the Pack changes the constituted domain state because the current source-authority relation changed.
- **FAIL** — the Pack continues to rely on Source A because freshness, provenance, confidence, historical primacy, availability or static hierarchy silently substitutes for current governing authority.
- **UNRESOLVED** — the Pack cannot independently represent the current source-authority relation, or the pair cannot be executed without changing a frozen non-authority dimension.

## Falsifier

**Can an unchanged, fresh, attributable source become non-governing without becoming stale, wrong or unavailable — and does the Pack notice?**
